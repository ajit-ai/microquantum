Analysis
========

Post-processing and analysis of experiment results.  Full API details live in
the generated reference; the links below jump straight to the relevant module.

* :class:`~microquantum.analysis.sampling.SamplingAnalysis` — measurement
  outcome distributions and statistics.
* :class:`~microquantum.analysis.expectation.ExpectationValueAnalysis` —
  observable expectation values from shots.
* :class:`~microquantum.analysis.state.StateAnalysis` — state fidelity and
  overlap diagnostics.
* :class:`~microquantum.analysis.statistics.StatisticsResult` — summary
  statistics (mean, standard error, …).
* :class:`~microquantum.analysis.aggregation.ResultAggregator` — combine
  analyses / records across runs.

See :doc:`/analysis/overview` for the narrative guide.
